## Add to AMP

1. **Configuration → Instance Deployment → Configuration Repositories**, add:
   ```
   silas-w/amp-templates:main
   ```
2. Click **Fetch Latest** and reload the page (Ctrl+F5).
3. The games appear under **Create Instance**.
